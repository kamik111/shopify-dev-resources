# Shopify Dev Resources

Practical checklists and reference material for Shopify merchants and developers —
scope templates, quote checklists, and buying guides you can use as-is. Maintained by the
team behind [shopify.ecom-store.pro](https://shopify.ecom-store.pro/), where each resource
links back to a full, fact-checked breakdown.

Everything here is meant to be useful on its own: open a file, work through it, done.

## Resources

| Resource | What it is |
| --- | --- |
| [Shopify Development Quote Checklist](checklists/shopify-development-quote-checklist.md) | Read and compare developer/agency quotes line by line — what a complete quote includes, red flags, benchmark rates to sanity-check against, and first-year recurring costs. |
| [Shopify Store Code Audit Checklist](checklists/shopify-store-code-audit-checklist.md) | Audit a store you did not build — 68 checks across theme generation, ghost code from removed apps, ScriptTags, dated checkout/Scripts liabilities, access and API scopes, tampering triage, and the fix-or-rebuild verdict. |
| [Shopify Trial Offers: Pre-flight Checklist](checklists/shopify-trial-offers-dev-checklist.md) | The three trial routes (public 3 months, AI-created store 4 months, 1MBB 6 months), where to verify each, and what to check before writing a term into code or docs. |

More resources will be added over time.
